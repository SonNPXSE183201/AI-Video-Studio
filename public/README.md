# Media assets

Đặt screen recording, ảnh và audio đã được duyệt vào đây. Chỉ dùng dữ liệu demo.

Quy ước:

- `footage/<campaign-id>/...` cho video quay thật.
- `audio/<campaign-id>/...` cho voice-over và nhạc có quyền sử dụng.
- `brand/...` cho logo/font được phê duyệt.

Trong code Remotion, tham chiếu bằng `staticFile('footage/...')` thay vì đường dẫn tuyệt đối.
