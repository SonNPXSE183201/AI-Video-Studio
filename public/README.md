# Public Assets & Web Client Directory

Thư mục chứa toàn bộ giao diện Web Studio, tài nguyên đa phương tiện và cấu hình dự án.

## Cấu Trúc Các Tệp Tin

- `index.html`: Giao diện Web Studio chính theo chuẩn Material Design 3 (M3).
- `app.js`: Logic điều khiển trình phát video Canvas 60fps, gọi API TTS, quản lý phân cảnh và đồng bộ phụ đề.
- `style.css`: Hệ thống thiết kế Dark Theme cao cấp chuẩn M3 (Design Tokens, Elevation, Typography, Shapes).
- `logo.jpg`: Logo chính thức của dự án đạt chuẩn hiển thị 8K UHD.
- `truong-khac/`: Chứa 15 hình ảnh phân cảnh Donghua retro 1994 mặc định của nhân vật Trương Khác (Quan Lộ Thương Đồ).
- `uploads/`: Nơi lưu trữ tự động các file âm thanh giọng đọc AI (TTS), file nhạc nền (BGM) và ảnh tải lên.
- `project-config.json`: File lưu trữ trạng thái cấu hình hiện tại của kịch bản, thời lượng các cảnh và đường dẫn media.
